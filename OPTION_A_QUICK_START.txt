STEP 2: DEPLOY BACKEND (10 minutes)

New Render Service:

  1. Go to https://render.com → Sign in
  2. New + → Web Service
  3. Connect repository → BikeTaxi
  4. Branch: v0/project-analysis-b16c254b
  
  Configuration:
  ├─ Name: biketaxi-api-prod
  ├─ Environment: Node
  ├─ Build: cd backend && npm install --legacy-peer-deps && npm run build:ts
  ├─ Start: cd backend && npm run start:ts
  └─ Region: Pick closest to users

  Environment Variables:
  ├─ DATABASE_URL: (your connection string)
  ├─ NODE_ENV: production
  ├─ JWT_SECRET: (run: openssl rand -base64 32)
  ├─ CORS_ORIGIN: (update in Step 3)
  └─ Others: See full guide

  Deploy → Wait 3-5 min → Get URL
  Example: https://biketaxi-api-prod.onrender.com

  Test:
  curl https://biketaxi-api-prod.onrender.com/health
  → Should return JSON with "status": "ok"

  Configuration:

TROUBLESHOOTING

Build Fails on Render?
  → Check build logs for errors
  → Verify package.json syntax
  → Check TypeScript compilation

Frontend Can't Reach API?
  → Check CORS_ORIGIN in Render
  → Verify NEXT_PUBLIC_API_URL in Vercel
  → Check browser console (F12)

Database Connection Error?
  → Verify DATABASE_URL format
  → Check credentials
  → Verify firewall rules in Neon/Supabase
