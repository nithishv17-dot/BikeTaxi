3-STEP DEPLOYMENT PROCESS
════════════════════════════════════════════════════════════════════════════

STEP 1: Set Up PostgreSQL Database (5 minutes)
  
  Choose one:
  
  Option A - Neon (Recommended)
    1. Go to https://neon.tech
    2. Sign up with GitHub
    3. Create new project
    4. Copy connection string
  
  Option B - Supabase
    1. Go to https://supabase.com
    2. Sign up with GitHub
    3. Create new project
    4. Copy connection string

STEP 2: Deploy Backend to Render (10 minutes)
  
  1. Go to https://render.com
  2. Sign in with GitHub
  3. New → Web Service
  4. Select your BikeTaxi repository
  5. Configure:
     - Name: biketaxi-api
     - Environment: Node
     - Build: npm install --legacy-peer-deps && npm run build:ts
     - Start: npm run start:ts
     - Root: backend
  6. Environment Variables:
     - DATABASE_URL: (from Neon/Supabase)
     - NODE_ENV: production
     - JWT_SECRET: (run: openssl rand -base64 32)
     - CORS_ORIGIN: https://biketaxi.vercel.app
  7. Deploy

STEP 3: Deploy Frontend to Vercel (10 minutes)
  
  1. Go to https://vercel.com
  2. Sign in with GitHub
  3. New Project → Import
  4. Select BikeTaxi repository
  5. Configure:
     - Framework: Next.js
     - Root Directory: frontend/react_app
  6. Environment Variables:
     - NEXT_PUBLIC_API_URL: https://biketaxi-api.render.com
     - NEXT_PUBLIC_ENVIRONMENT: production
  7. Deploy

TOTAL DEPLOYMENT TIME: ~25 minutes

TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════

Problem: Build fails on Render
  Solution: Check package.json dependencies, verify TypeScript compilation

Problem: Database connection fails
  Solution: Verify DATABASE_URL format, check firewall rules

Problem: CORS errors
  Solution: Verify CORS_ORIGIN in Render, check API_URL in Vercel

Problem: Frontend can't reach API
  Solution: Verify NEXT_PUBLIC_API_URL points to Render URL

Problem: Environment variables not working
  Solution: Ensure variables are set in service settings, restart deploy
